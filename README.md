# The Mehdi Verse — Shared Convex Backend

Shared [Convex](https://convex.dev) backend powering all **The Mehdi Verse** sample applications.

## Architecture

This repo owns the single Convex deployment. All 53+ app repos are **consumers** that connect via `VITE_CONVEX_URL`.

```
this repo  ← owns convex/ folder, schema, all server-side functions
app-one    ← frontend only, connects via VITE_CONVEX_URL
app-two    ← frontend only, connects via VITE_CONVEX_URL
...
```

Tables are namespaced with app prefixes (e.g. `crm_contacts`, `expense_tracker_expenses`) so all apps coexist cleanly in one deployment.

## Getting Started

### Prerequisites

- Node.js 22+
- A [Convex](https://convex.dev) account

### Setup

```bash
# Install dependencies
npm install

# Start Convex dev server (creates deployment on first run)
npx convex dev

# This generates .env.local with your CONVEX_DEPLOYMENT URL
```

### Generate API types for app repos

```bash
npx convex-helpers ts-api-spec
```

Copy the generated `api.ts` into each app repo.

## Project Structure

```
convex/
  schema.ts          # All table definitions (prefix-namespaced)
  tsconfig.json      # Convex TS config
  _generated/        # Auto-generated by Convex CLI
  _apps/             # One file per app with stub query/mutation
    crm.ts
    expense-tracker.ts
    ...
```

## Deployment

- **Dev**: `npx convex dev` (watches for changes)
- **Production**: Push to `main` triggers GitHub Actions → `npx convex deploy`
- **Releases**: Push a tag like `v0.1.0` to create a GitHub Release

### Required Secrets (GitHub → Settings → Secrets)

| Secret | Description |
|--------|-------------|
| `CONVEX_DEPLOY_KEY` | Production deploy key from Convex dashboard |
